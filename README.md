# مداد

دفتر دراسة شخصي: دفاتر، أقسام، دروس ومفاهيم مترابطة، مع حالة يدوية للفهم، وبحث، ومراجعة، وحفظ على الجهاز.

## تشغيل نسخة Ubuntu الجاهزة

نزّل حزمة `Midad-0.1.0-Ubuntu.tar.gz` وفك ضغطها، ثم شغّل `bash start.sh` من المجلد المستخرج.
تحتاج Python 3.10 أو أحدث ومتصفحاً حديثاً فقط. يفتح التطبيق دائماً على `http://127.0.0.1:8765/`.
يمكن إضافته إلى قائمة التطبيقات دون sudo عبر `python3 install.py`.

البيانات في ملف متصفحك الشخصي وليست داخل مجلد البرنامج. استعمل العنوان والمتصفح نفسيهما، ونزّل نسخة JSON بانتظام.
للانتقال من نسخة أونلاين، صدّر النسخة هناك ثم استعدها محلياً. المزامنة وAI خارج هذا الإصدار.

## تطبيق Windows

يتوفر مُثبّت EXE ونسخة ZIP لنفس التطبيق، يستهدفان Windows 10 وWindows 11 Home/Pro بمعمارية x64.
راجع [دليل Windows](docs/WINDOWS.md) للتثبيت ونقل الملاحظات وفحوص القبول.
لبناء الحزم: `npm run package:windows`. تحتاج حزم Windows فحص التشغيل الفعلي على كل نظام مستهدف.

## التطوير

Node.js 24:

```bash
npm ci --ignore-scripts
npm run dev
npm run typecheck
npm run lint
npm test
npm run package:local
```

يبني `build:local` تطبيق متصفح مستقلاً في `dist-local/`. يحافظ `npm run build` على مسار TanStack/Nitro الأصلي.

الحفظ يعتمد على معاملات IndexedDB مع فحص إصدار لمنع نافذة قديمة من محو تعديل أحدث. لا يستبدل التطبيق البيانات عند تعذر فتحها.
الاستعادة تتحقق من الملف كله وتعرض تأكيداً وتحفظ نسخة للرجوع. التراجع عن الحذف يشمل آخر عملية ضمن الجلسة فقط.

الكتابة تدعم العربية مع كود ومعادلات وجداول وصور. اربط الصفحات من اللوحة أو بكتابة `[[عنوان الصفحة]]`.
